# StudentHub Management System

StudentHub is a web-based Student Management System designed to manage
students, teachers, departments, courses, enrollment, attendance,
grades, fees, timetables, announcements, and user accounts.

## Current Features

- User registration
- Administrator account approval
- Role-based authentication
- Admin dashboard
- Student management
- Teacher management
- Department management
- Program management
- Course management
- Enrollment management
- Attendance management
- Grade management
- Fee management
- Timetable management
- Announcements
- Account approvals
- Activity log

## Technology Stack

### Frontend

- React
- TypeScript
- React Router
- Vite
- Lucide React

### Backend

- Node.js
- Express
- JWT authentication
- bcrypt

### Database

- MYSQL
